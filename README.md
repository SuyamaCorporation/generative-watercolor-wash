# 04 - ジェネレーティブ水彩ウォッシュ

**ビルド日**: 2026-11-03
**カテゴリ**: visual
**slug**: generative-watercolor-wash

## 概要
HTML5 CanvasとLCG疑似乱数を使ったジェネレーティブ水彩画アプリ。半透明の不規則なブロブにラジアルグラデーションとエッジ色素蓄積エフェクトを重ね、水彩画のにじみ・ぼかし表現を再現します。

## 機能
- 色相範囲スライダ（0〜360°）で色調をコントロール
- 透明度スライダで水彩の薄さ・濃さを調整
- ブロブサイズスライダで描画要素の大きさを変更
- にじみ広がりスライダでエッジのにじみ量を調整
- Generateボタンで新しいランダムシードによる構図を生成
- クリアボタンでキャンバスをリセット
- PNGダウンロードボタンで画像を保存（canvas.toDataURL）
- ページ読み込み時に自動生成
